 stack is a linear data structure that follows the LIFO (Last In, First Out) principle. This means the last element added to the stack is the first one to be removed, much like a stack of plates or books.

Core Operations

• Push: Adds a new element to the top of the stack.
• Pop: Removes and returns the top element from the stack.
• Peek / Top: Views the top element without removing it.
• IsEmpty: Checks if the stack has any elements.

Common Applications

• Function Call Management: Managing local variables, return addresses, and recursive function calls in the call stack.
• Undo Mechanisms: Reverting actions in text editors, graphic design tools, or web browsers.
• Expression Evaluation: Parsing syntax, checking balanced brackets, and converting infix to postfix expressions.
• Backtracking: Algorithms like depth-first search (DFS) in graphs or trees.
